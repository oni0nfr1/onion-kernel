# Onion Kernel Default Bitmap Font

`default.onft` is a modified font derived from the `ter-v32n` glyph data in
Terminus Font 4.49.1. It was converted from PSF2 to ONFT v1 and reduced to the
128 glyphs in the ONFT v1 ASCII repertoire.

The modified font is distributed under the SIL Open Font License, Version 1.1.
It does not use the Reserved Font Name "Terminus Font" as its primary font
name. See `OFL.txt` for the original copyright notice and full license text.
